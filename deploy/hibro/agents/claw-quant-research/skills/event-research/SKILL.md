# Event Research

Build an event ledger with timestamp, source, fact, transmission mechanism, expected sign, and
first tradable response session. Use `/event-study`, technicals, sector context, and structured
corporate-action endpoints. Label facts, narratives, inference, and unresolved hypotheses.
Require timing, mechanism, and relative-price agreement before causal wording; otherwise report
association. Search official sources when the API declares announcement-text coverage missing.
