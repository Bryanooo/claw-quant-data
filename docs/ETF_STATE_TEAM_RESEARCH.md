# ETF 份额资金流与国家队证据研究

## 定位

这项能力属于 `claw-quant-data` 的研究层，而不是只存在于某个 Agent Skill 中。
服务端负责可复现的事实、计算、证据分级和质量限制；Skill 负责选择窗口、调用接口、
结合研究问题组织解释和生成报告。任何客户端都不应自行复制份额换算或身份判定规则。

## 已提供接口

| 接口 | 用途 |
|---|---|
| `GET /api/v1/research/etfs/flows` | 按 ETF 和跟踪指数汇总份额变化、估算申赎资金、指数收益和资金迁移候选 |
| `GET /api/v1/research/etfs/state-team-signals` | 在上述事实之上输出证据等级，并明确区分市场流量、疑似和已确认 |

对应 CLI：

```bash
./clawq research etf-flows --lookback-observations 5 --as-of 2026-09-18
./clawq research state-team-signals \
  --lookback-observations 5 --minimum-flow-yi 5 --as-of 2026-09-18
```

## 计算口径

`etf_share_size.total_share` 的单位是万份，净值单位是元/份，因此：

```text
估算申赎资金（亿元） = （期末总份额 - 期初总份额） × 期末单位净值 ÷ 10,000
```

优先使用 NAV；NAV 缺失时使用 `total_size / total_share` 的隐含净值。不能用 ETF
规模变化直接代替资金流，因为规模同时受到价格涨跌影响。跟踪相同指数的多个 ETF
按 `etf_basic.index_code` 聚合，避免只观察单一产品造成偏差。

`rotation_pairs` 只把同一窗口最大的流出和流入暴露配对，表示横截面共现，不表示
已经追踪到同一投资者的资金转移。

## 证据分级

1. `market_flow_only`：只有份额和市场数据，只能证明市场整体净申购或净赎回。
2. `suspected`：还需要已知持有 ETF 重叠、跨产品同步、逆市场行为和政策事件等证据。
3. `confirmed`：必须存在正式公告或基金定期报告中的持有人身份和份额变化。

当前 Tushare 数据没有 ETF 投资者身份，因此接口不会生成 `confirmed` 结果。正式报告
数据源接入前，所有候选都保留 `state_team_confirmed=false`，防止把做市、套利、联接
基金、保险或普通投资者的申赎误报为国家队操作。

## 数据与初始化

- `etf_share_size`：每日份额、规模、净值和收盘价；日常任务在次日 09:15 编排。
- `etf_basic`：基金、管理人和跟踪指数映射。
- `index_daily`：验证资金方向对应的指数表现。
- 全量初始化从 2009-01-05 起按 SSE 开市日创建完整性保护任务；2009 年以前的实测
  分区为空，不生成无意义任务。
- 专项补采命令只创建缺失交易日，重复执行依靠幂等键和数据库唯一约束保证安全：

```bash
python scripts/manage_research_backfills.py \
  --group etf-flow --start-date 2009-01-05 --end-date 2026-09-18
```

## 已知事件回测样例

以官方确认扩大 ETF 增持范围的 2024-02-06 为截止日，使用最近 5 个观测变化，系统
得到沪深300约 +525.51 亿元、中证500约 +209.81 亿元、中证1000约 +190.34 亿元、
创业板指约 +104.82 亿元、上证50约 +50.85 亿元、科创50约 +40.02 亿元的份额资金流
代理。宽基同步申购、部分指数同期明显下跌，符合逆市场稳定型信号。该样例证明份额层
能捕捉已知事件，但“已确认”标签仍来自官方公告，而不是由模型反推身份。

## 尚缺数据源

`official-etf-holder-reports` 待办只接受交易所或基金管理人发布的正式年报、中报及相关
季报。接入时必须保存报告期、持有人原始名称、标准实体、份额、比例、来源 URL、文件
哈希和解析版本。中央汇金投资有限责任公司、中央汇金资产管理有限责任公司、中国证券
金融股份有限公司等实体应分别存储并通过可审计的实体关系表归类，不能用模糊关键词
把所有国有机构归为国家队。

## Skill 边界

ETF 研究 Skill 可以：

- 先检查 `/api/v1/research/readiness`；
- 根据问题选择 5/20/60/250 个观测窗口；
- 调用资金流和证据信号接口；
- 结合官方消息、市场表现和其他研究接口形成文字或图表；
- 在结论中展示证据等级、数据日期和限制。

Skill 不可以自行重算资金流、绕过证据等级、把 `market_flow_only` 改写成“国家队已
买入”，也不负责采集、任务重试或直接访问数据库。
