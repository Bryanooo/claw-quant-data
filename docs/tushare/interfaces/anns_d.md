# `anns_d` — 上市公司全量公告

- 分类：大模型语料
- 功能：获取全量公告数据，提供pdf下载URL
- Token 权限：**无权限**（Tushare 明确返回无访问权限）
- 官方权限要求：本接口为单独权限，请参考 权限说明
- 官方文档：[doc 176](https://tushare.pro/document/2?doc_id=176)
- HTTP：`POST http://api.tushare.pro`
- claw-quant：未实现；代码：无

## 输入契约

| 参数 | 类型 | 必选 | 说明 |
|---|---|:---:|---|
| `ts_code` | str | N | 股票代码 |
| `ann_date` | str | N | 公告日期（yyyymmdd格式，下同） |
| `start_date` | str | N | 公告开始日期 |
| `end_date` | str | N | 公告结束日期 |

## 输出契约

| 字段 | 类型 | 默认显示 | 说明 |
|---|---|:---:|---|
| `ann_date` | str | Y | 公告日期 |
| `ts_code` | str | Y | 股票代码 |
| `name` | str | Y | 股票名称 |
| `title` | str | Y | 标题 |
| `url` | str | Y | URL，原文下载链接 |
| `rec_time` | datetime | N | 发布时间 |

## HTTP 请求示例

```bash
curl -X POST 'http://api.tushare.pro' \
  -H 'Content-Type: application/json' \
  -d '{
  "api_name": "anns_d",
  "token": "${TUSHARE_TOKEN}",
  "params": {
    "ts_code": "000001.SZ"
  },
  "fields": ""
}'
```

## 官方 SDK 示例

```python
pro = ts.pro_api()

df = pro.anns_d(ann_date='20230621')
```
