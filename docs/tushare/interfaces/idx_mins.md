# `idx_mins` — 指数历史分钟行情

- 分类：指数专题
- 功能：获取交易所指数分钟数据，支持1min/5min/15min/30min/60min行情，提供Python SDK和 http Restful API两种方式
- Token 权限：**无权限**（Tushare 明确返回无访问权限）
- 官方权限要求：需单独开权限，正式权限请参阅 权限说明 ，可以 在线开通 分钟权限。
- 官方文档：[doc 419](https://tushare.pro/document/2?doc_id=419)
- HTTP：`POST http://api.tushare.pro`
- claw-quant：未实现；代码：无

## 输入契约

| 参数 | 类型 | 必选 | 说明 |
|---|---|:---:|---|
| `ts_code` | str | Y | 指数代码，e.g. 000001.SH |
| `freq` | str | Y | 分钟频度（1min/5min/15min/30min/60min） |
| `start_date` | datetime | N | 开始日期 格式：2023-08-25 09:00:00 |
| `end_date` | datetime | N | 结束时间 格式：2023-08-25 19:00:00 |

## 输出契约

| 字段 | 类型 | 默认显示 | 说明 |
|---|---|:---:|---|
| `ts_code` | str | Y | 指数代码 |
| `trade_time` | str | Y | 交易时间 |
| `open` | float | Y | 开盘价 |
| `close` | float | Y | 收盘价 |
| `high` | float | Y | 最高价 |
| `low` | float | Y | 最低价 |
| `vol` | int | Y | 成交量(股) |
| `amount` | float | Y | 成交金额（元） |

## HTTP 请求示例

```bash
curl -X POST 'http://api.tushare.pro' \
  -H 'Content-Type: application/json' \
  -d '{
  "api_name": "idx_mins",
  "token": "${TUSHARE_TOKEN}",
  "params": {
    "ts_code": "000001.SH",
    "freq": "D"
  },
  "fields": ""
}'
```

## 官方 SDK 示例

```python
pro = ts.pro_api()

#获取上证综指000001.SH的历史分钟数据
df = pro.idx_mins(ts_code='000001.SH', freq='1min', start_date='2023-08-25 09:00:00', end_date='2023-08-25 19:00:00')
```
