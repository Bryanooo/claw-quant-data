# Valuation and Shareholder Return

Use stock valuation and repurchase-progress contracts. Prefer own-history valuation before peers
and check comparability. Disclose every DCF/DDM scenario assumption. Separate repurchase proposal,
approval, implementation, and completion; use latest cumulative execution rather than summing
cumulative notices. If dividend, dilution, unlocking, or ownership history is incomplete, label
total shareholder return partial rather than promoting repurchase alone to a complete measure.
