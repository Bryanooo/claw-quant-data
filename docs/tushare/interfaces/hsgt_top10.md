# `hsgt_top10` — 沪深股通十大成交股

- 分类：股票数据/行情数据
- 功能：获取沪股通、深股通每日前十大成交详细数据，每天18~20点之间完成当日更新
- Token 权限：**有权限**（接口返回成功）
- 官方权限要求：官方页面未单独声明
- 官方文档：[doc 48](https://tushare.pro/document/2?doc_id=48)
- HTTP：`POST http://api.tushare.pro`
- claw-quant：已实现；代码：[collectors/stock/market/hsgt_top10.py:HsgtTop10Collector](../../../collectors/stock/market/hsgt_top10.py)

## 输入契约

| 参数 | 类型 | 必选 | 说明 |
|---|---|:---:|---|
| `ts_code` | str | N | 股票代码（二选一） |
| `trade_date` | str | N | 交易日期（二选一） |
| `start_date` | str | N | 开始日期 |
| `end_date` | str | N | 结束日期 |
| `market_type` | str | N | 市场类型（1：沪市 3：深市） |

## 输出契约

| 字段 | 类型 | 默认显示 | 说明 |
|---|---|:---:|---|
| `trade_date` | str | Y | 交易日期 |
| `ts_code` | str | Y | 股票代码 |
| `name` | str | Y | 股票名称 |
| `close` | float | Y | 收盘价 |
| `change` | float | Y | 涨跌额 |
| `rank` | int | Y | 资金排名 |
| `market_type` | str | Y | 市场类型（1：沪市 3：深市） |
| `amount` | float | Y | 成交金额（元） |
| `net_amount` | float | Y | 净成交金额（元） |
| `buy` | float | Y | 买入金额（元） |
| `sell` | float | Y | 卖出金额（元） |

## HTTP 请求示例

```bash
curl -X POST 'http://api.tushare.pro' \
  -H 'Content-Type: application/json' \
  -d '{
  "api_name": "hsgt_top10",
  "token": "${TUSHARE_TOKEN}",
  "params": {
    "trade_date": "20260829"
  },
  "fields": ""
}'
```

## 官方 SDK 示例

```python
pro = ts.pro_api()

pro.hsgt_top10(trade_date='20180725', market_type='1')
```

## claw-quant 存储契约

该接口由专用采集器写入规范化业务表，主键和字段转换以链接代码为准。

> 权限状态来自实际 Token 探测；示例中的 Token 仅为环境变量占位符，不包含真实密钥。
