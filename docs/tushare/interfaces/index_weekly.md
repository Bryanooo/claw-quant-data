# `index_weekly` — 指数周线行情

- 分类：指数专题
- 功能：获取指数周线行情
- Token 权限：**有权限**（接口返回成功）
- 官方权限要求：用户需要至少600积分才可以调取，积分越多频次越高，具体请参阅 积分获取办法
- 官方文档：[doc 171](https://tushare.pro/document/2?doc_id=171)
- HTTP：`POST http://api.tushare.pro`
- claw-quant：已实现；代码：[collectors/index/weekly.py:IndexWeeklyCollector](../../../collectors/index/weekly.py)

## 输入契约

| 参数 | 类型 | 必选 | 说明 |
|---|---|:---:|---|
| `ts_code` | str | N | TS代码 |
| `trade_date` | str | N | 交易日期 |
| `start_date` | str | N | 开始日期 |
| `end_date` | str | N | 结束日期 |

## 输出契约

| 字段 | 类型 | 默认显示 | 说明 |
|---|---|:---:|---|
| `ts_code` | str | Y | TS指数代码 |
| `trade_date` | str | Y | 交易日 |
| `close` | float | Y | 收盘点位 |
| `open` | float | Y | 开盘点位 |
| `high` | float | Y | 最高点位 |
| `low` | float | Y | 最低点位 |
| `pre_close` | float | Y | 昨日收盘点 |
| `change` | float | Y | 涨跌点位 |
| `pct_chg` | float | Y | 涨跌幅 |
| `vol` | float | Y | 成交量（手） |
| `amount` | float | Y | 成交额（千元） |

## HTTP 请求示例

```bash
curl -X POST 'http://api.tushare.pro' \
  -H 'Content-Type: application/json' \
  -d '{
  "api_name": "index_weekly",
  "token": "${TUSHARE_TOKEN}",
  "params": {
    "trade_date": "20260829"
  },
  "fields": ""
}'
```

## 官方 SDK 示例

```python
pro = ts.pro_api()

df = pro.index_weekly(ts_code='000001.SH', start_date='20180101', end_date='20190329', fields='ts_code,trade_date,open,high,low,close,vol,amount')
```

## claw-quant 存储契约

该接口由专用采集器写入 `index_weekly` 规范化业务表，业务主键为
`(ts_code, trade_date)`。自动任务按上一个完整周的最后交易日生成
`trade_date` 分区，使用 `limit=1000` 和递增 `offset` 拉取全市场；只有返回短页
证明分页耗尽后才记录 `complete`。重复页或达到 `max_pages` 会记录为不完整并重试，
不会把 1000 行整数上限误判成完整结果。

真实验证：`trade_date=20260828` 共 15 页、14,312 行，任务证据为
`verified=true`、`exhausted=true`。

> 权限状态来自实际 Token 探测；示例中的 Token 仅为环境变量占位符，不包含真实密钥。
