# `cn_cpi` — 居民消费价格指数

- 分类：宏观经济/国内宏观/价格指数
- 功能：获取CPI居民消费价格数据，包括全国、城市和农村的数据
- Token 权限：**有权限**（接口返回成功）
- 官方权限要求：用户积累600积分可以使用，具体请参阅 积分获取办法
- 官方文档：[doc 228](https://tushare.pro/document/2?doc_id=228)
- HTTP：`POST http://api.tushare.pro`
- claw-quant：已实现（契约通用采集器：原始层+强类型标准表）；代码：[collectors/tushare_raw.py:CatalogRawCollector](../../../collectors/tushare_raw.py)

## 输入契约

| 参数 | 类型 | 必选 | 说明 |
|---|---|:---:|---|
| `m` | str | N | 月份（YYYYMM，下同），支持多个月份同时输入，逗号分隔 |
| `start_m` | str | N | 开始月份 |
| `end_m` | str | N | 结束月份 |

## 输出契约

| 字段 | 类型 | 默认显示 | 说明 |
|---|---|:---:|---|
| `month` | str | Y | 月份YYYYMM |
| `nt_val` | float | Y | 全国当月值 |
| `nt_yoy` | float | Y | 全国同比（%） |
| `nt_mom` | float | Y | 全国环比（%） |
| `nt_accu` | float | Y | 全国累计值 |
| `town_val` | float | Y | 城市当月值 |
| `town_yoy` | float | Y | 城市同比（%） |
| `town_mom` | float | Y | 城市环比（%） |
| `town_accu` | float | Y | 城市累计值 |
| `cnt_val` | float | Y | 农村当月值 |
| `cnt_yoy` | float | Y | 农村同比（%） |
| `cnt_mom` | float | Y | 农村环比（%） |
| `cnt_accu` | float | Y | 农村累计值 |

## HTTP 请求示例

```bash
curl -X POST 'http://api.tushare.pro' \
  -H 'Content-Type: application/json' \
  -d '{
  "api_name": "cn_cpi",
  "token": "${TUSHARE_TOKEN}",
  "params": {},
  "fields": ""
}'
```

## 官方 SDK 示例

```python
pro = ts.pro_api()

df = pro.cn_cpi(start_m='201801', end_m='201903')


#获取指定字段
df = pro.cn_cpi(start_q='201801', end_q='201903', fields='month,nt_val,nt_yoy')
```

## claw-quant 存储契约

该接口采用两阶段持久化：上游响应先无损写入 `tushare_raw_record`，随后按契约转换到
强类型标准表 `tushare_norm_cn_cpi`。标准表字段、类型、日期列、系统血缘字段和
稳定性规则见[标准化表契约](../tables/cn_cpi.md)。转换失败记录进入
`sys_tushare_normalization_error`，契约外字段保存在 `_extra_payload` 并登记到
`sys_tushare_schema_drift`；原始响应始终可用于修复后重放。

> 权限状态来自实际 Token 探测；示例中的 Token 仅为环境变量占位符，不包含真实密钥。
