# 宏观研究方法

## 数据口径

- `growth` 使用 GDP 同比与制造业 PMI；PMI 的 50 只是扩张/收缩边界，环比变化表达边际方向。
- `inflation` 使用 CPI 与 PPI 同比及其变化；居民端和生产端冲突时保持分项结论。
- `liquidity` 使用 M1/M2 同比、社融、Shibor 与 LPR；利率下降是宽松证据之一，不能单独代表信用扩张。
- `regime` 是增长和通胀方向的透明组合；流动性作为独立条件展示，不通过隐藏权重修改周期标签。

当前标准表按经济观察期保存，不完整保留每次官方首次发布时间和历次修订值。因此历史
`as_of` 是观察期截止视图，不是严格的实时历史数据快照。涉及“当时市场知道什么”时，
必须补充官方发布日与历史版本证据。

## 研究顺序

1. 分别判断增长、通胀和流动性，列出相互冲突的指标。
2. 检查投资日历中的发布状态和下一个关键事件。
3. 描述传导渠道：盈利、利率、风险偏好、汇率或商品成本。
4. 使用市场宽度、行业研究或跨资产接口验证市场是否已经交易该状态。
5. 明确可能改变判断的下一项数据，而不是把当前标签外推为确定预测。

财政脉冲、海外政策、外部平衡、商品库存和完整发布版本仍是声明过的数据缺口。
