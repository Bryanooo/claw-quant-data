# Event Research

Build an event ledger with timestamp, source, fact, mechanism, expected sign, and first tradable
response session. Use event study plus benchmark and sector context. Require timing, mechanism,
and relative-price agreement for causal wording; otherwise report association. Search official
sources when announcement-text coverage is missing.
